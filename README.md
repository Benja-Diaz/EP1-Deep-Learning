# Evaluación Parcial 1 - Deep Learning

Proyecto desarrollado para la asignatura Deep Learning.

## Objetivo

Implementar una red neuronal artificial multicapa (MLP) utilizando TensorFlow/Keras para resolver un problema de clasificación multietiqueta.

El modelo predice tres variables objetivo:

- interes_tecnologia
- interes_moda
- interes_deportes

## Herramientas utilizadas

- Python
- Google Colab
- TensorFlow / Keras
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Contenido del proyecto

El notebook incluye:

- Carga y exploración de datos.
- Tratamiento de valores faltantes y outliers.
- Escalado de variables.
- División en entrenamiento, validación y prueba.
- Implementación de una red neuronal MLP.
- Comparación de funciones de activación.
- Comparación de funciones de pérdida.
- Comparación de optimizadores.
- Regularización mediante Dropout y Early Stopping.
- Evaluación de hiperparámetros.
- Evaluación mediante Accuracy, Precision, Recall y F1-Score.
- Selección y evaluación del modelo final.

## Ejecución

1. Abrir el archivo `.ipynb` en Google Colab.
2. Cargar el dataset utilizado en el proyecto.
3. Ejecutar las celdas en orden desde el inicio.
4. Revisar las tablas y gráficos generados durante el entrenamiento y evaluación.
